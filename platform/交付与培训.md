# 共享试办版交付与培训

## 发给同事

所有人打开组织者提供的同一个 GitHub 试办网址，用分配的工作台账号登录。首次登录按提示设置自己的密码。服务在 GitHub 上运行，组织者关掉电脑后仍可办理。若环境因空闲休眠，组织者唤醒原实例并恢复端口后，大家继续使用原网址。

## 功能设计与数据流

Vue 页面通过 FastAPI 完成订单、任务、审批和归集。服务端按当前部门岗位及记录关系检查权限。科研通过内审后发布项目基线。财务以同订单的项目编号登记费用及工时；同一人不能在同一版本替两线联签。主管、独立经理和按条件参与的总监依序审核。会审人通过个人收件箱回复指定事项。客户退回后重新送审。归档包包含审核历史、交付清单、文书、材料及其校验值。

年度账表以已审工作底稿生成并保留版本，支持三口径独立下载和差异复核。关系数据在 SQLite，附件按内容校验值核对。已有试办账号、订单和历史快照在常规部署中保留。API 交互文档在同一站点的 `/api/docs`，机器可读说明在 `/api/openapi.json`。

## 恢复演练

在应用主机运行 `python platform/backup_trial.py .local/shared-trial .local/backups/试办日期`，最后一个参数换成尚未存在的目录。备份包含数据库和登记的任务、客户附件。把输出交给获授权的保管人。恢复测试时在隔离环境中让 WORKSPACE_DATA 指向备份的副本，启动同一版本应用，重新登录，核对订单、两版提交记录、归档附件的 SHA-256。备份不复制历史会话、初始密码表或会话密钥。开发机上的单机恢复不能代替正式云异地容灾验收。
