# 在自己的电脑上验收

适用于 64 位 Windows。把压缩包完整解压到 D 盘的普通文件夹，打开“科研财税协同”，双击“双击启动.cmd”。黑色窗口请保持打开。浏览器会自动打开本机工作台。如果浏览器没有弹出，可复制启动窗口最后显示的完整网址。

第一次打开，请自己设置一个至少八位、含字母和数字的验收密码。系统会建立青禾试验科技的虚构订单及十个本地岗位。各验收账号使用你设置的同一个初始验收密码。之后由管理员新开的账号，在第一次登录时自行改密。可打开另一个浏览器窗口或使用另一个页签，分别登录不同岗位。

## 建议先试一笔订单

1. 选择“科研承办”，在工作台打开“青禾温控试验 · 确认立项清单”，点击“确认接件”，再点“确认并保存”。
2. 点“编辑作业底稿”，写一句作业说明，点“添加项目”。示例项目编号 QH-01，名称为温控样机，预算 10000 元。填写负责人、起止日期、研发目标、创新点和技术不确定性，保存。
3. 到“文书与材料”选一套立项决议模板，填完栏目，下载 Word。可以上传虚构文件，再回到“办理”提交审核。
4. 退出后选择“科研主管”，打开同一任务，点“退回修改”并写下缺项。以科研承办身份修改并重新提交。科研主管通过后，由“科研复审经理”通过。打开“审核时间线”可以分别查看两次提交。
5. 用“财务承办”登录，打开同一订单的费用归集任务并接件。页面会显示 QH-01。点“登记费用凭证”，选择 QH-01 并录入虚构凭证。在“费用与物料”可以录考勤工资、研发和非研发工时，由财务主管审工时，财务承办分摊工资。合计工时须等于实到工时。
6. 回到财务任务填写并保存作业说明。财务承办、科研协办分别到同一任务的“协作与记录”点“本线资料联审”，核对同一稿后由财务承办提交。财务主管、财务复审经理依次审核。重大任务还需本线总监终审。以经理身份登记客户签收，填写虚构签收意见，再确认归档。到“交付归档”下载 ZIP，查看文书、附件及审核记录。
7. 以“派单经理”登录，在“费用与物料”生成年度辅助账，选择青禾客户和虚构凭证所属年度。可下载 Excel 逐笔复核。

## 想试其他功能

在客户档案、服务合同、服务订单中建立自己的虚构案例，合同先由独立总监审批，经理再建订单和派单。协办人在派单时指定。结题任务指定另一条业务线的协办人，由两线在同一底稿上联签。修改后须重新确认。调整任务在“协作与记录”登记变更，通过内部审核后更新项目基线。

“系统管理”使用账号 admin 登录，可以开设、停用、重置其他账号，维护部门并查看日志。材料的上一版本保留可下载。正式签章需要单位提供服务商环境。

## 关闭、再次打开与备份

关闭启动窗口即可停止服务。下次双击同一份启动文件，继续办理。需要备份时先关闭启动窗口，再复制整个“科研财税协同”文件夹到受控磁盘；恢复时从备份文件夹启动。runtime 文件夹包含本机数据、附件及会话密钥，请只保存在本机受控位置。

## 查阅验收范围

源码仓库 platform/验收范围.md 记录已有验证、待核项目及外部依赖。浏览器中的公开演示使用独立示例数据，本机资料保存在解压目录。
## 办公室联机

给业务同事：先定两个人，甲负责派单，乙负责接件。两台电脑使用同一个单位内部网址，个人账号各不相同。在甲电脑新建一笔虚构订单并派给乙，乙刷新任务列表后应能接件；甲刷新后应看到“办理中”。走完整审批时，另安排独立的主管、复审经理；重大事项加总监。此次用测试材料登记签收。

给负责网络的同事：在运行系统的电脑完成单机初始化。在“系统管理”给两位试用者分别开户，选择业务部门与岗位，设置各自的临时密码。工号使用单位测试编号，例如 T-01、T-02。以经理账号建立虚构客户、审批合同、建立订单，或在同一部门使用已有虚构订单；合同审批由独立总监完成。系统管理员在本机操作。办公室入口只允许个人测试账号登录。

请在企业专网内选定一台电脑，准备其固定内网 IPv4 地址、同事能解析的内部主机名、单位电脑已信任且名称匹配的 HTTPS 证书及其 PEM 私钥。这些文件由负责网络的同事直接保管在本机。按单位安排将 18766 端口的访问范围限定在指定办公网段或单位批准的 VPN，确认路由和防火墙。服务器电脑不需要购买公网域名。

在“办公室联机.cmd”同一文件夹新建 UTF-8 的“办公室配置.json”。将下方示例替换为实际地址、主机名和证书路径。

    {
      "内网地址": "192.168.10.20",
      "内网主机名": "rdtest.office.example",
      "证书文件": "office-cert.pem",
      "私钥文件": "office-key.pem",
      "端口": 18766
    }

双击“办公室联机.cmd”，把窗口显示的内部网址发给试用人。在第二台单位电脑打开该网址，检查浏览器证书正常，并用本人岗位接件。两台电脑都连接这一台服务主机，共用同一笔业务记录。本机启动窗口与办公室窗口可以共存。备份前请关闭两个窗口。

可以转给办公室负责人的一句话：

我们想让两位同事在办公室用各自账号试办同一笔虚构研发订单，先不盖章。请帮忙确认哪台电脑能作为测试主机、谁负责内网网址和证书，以及是否需要预算审批。
