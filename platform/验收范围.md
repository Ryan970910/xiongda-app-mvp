# V3.0 本机验收范围

此版本供单位用虚构资料试办。公开的 GitHub Pages 工作台和本机工作台使用两套独立存储。大模型相关接口未接入。

| 说明书验收项 | 本机可验的内容 | 仍需核对的边界 |
| --- | --- | --- |
| 账号和组织 | 管理员开户、岗位、临时授权、部门、停启用、重置、首登改密、历史密码、失败锁定、会话续期、访问日志。办公室入口使用个人账号。 | 内置十个岗位共用用户自设的单机验收密码。办公室入口禁用这些样例身份。跨业务线兼岗的数据范围及正式账号策略需按单位组织验收。 |
| 客户、合同、订单 | 档案查重、客户全景、带可见范围的客户及合同附件、合同审批、收款登记、同单多任务、按客户导出服务档案。 | 正式合同、客户回传及密级制度须由单位核对。 |
| 任务和双线协同 | 单笔与批量派单、协办调整、接件或拒收、挂起与恢复、资料登记、跨线补件、资料联审、逐级通过或退回、前置立项清单、客户签收、只读归档。审批回避，管理员可调重大事项终审条件。 | 各岗位在真实办公网的覆盖面和员工名单由单位确认。本版签收由经办人登记。 |
| 科研作业与模板 | 五类核心文种各 11 套，另有四类配套报告及四类中期调整。支持在线填栏目、Word、浏览器预览及打印 PDF。核准的决议产生编号和项目清单附件。模板版本保留，项目含人员、预算分项及里程碑。 | 现有模板依据说明书的栏目制作。单位抬头、红头套打版心、每份正式表样及电子签章仍需拿单位原件对版。 |
| 调整与结题 | 调整单记录原值、新值和影响，末级内审后更新基线。验收指标、实绩、经费与已审凭证对照、失败原因、专家意见、证明文件和双线联签；变更后重新联签。 | 专家身份及真实盖章留待单位提供。 |
| 人工与物料 | 月度工资考勤、研发及非研发工时、工时审核、按分分摊、试制申请及审批、领料、流转、退料、样品、消耗、处置和余额。消耗产生直接投入底稿，处置收入关联原单。 | 本机使用人工登记的可用库存、凭证与分摊依据。仓库、工资及外部财务软件的实际数据接口需单独联调。 |
| 三口径、辅助账 | 会计、高企、加计数据列与差异；2015 样式四类账、2021 样式项目账、年度汇总、A107012 行次复核、凭证索引、版本留存与 Excel。其他费用限额、境外委托上限、跨年产品材料、资产形成与实际税前摊销分别核算。勾稽不平的申报核对导出受限。 | 工作簿为内部复核表样。税前摊销数、费用正列举标记、政策适用比例及补助对应关系需要业务人员输入和复核。会计师对真实账套、年度申报表行次和单位例外政策的签认尚未完成。 |
| 证明与风险 | 真实附件、项目关联、分类、版本链、下载校验，知识产权登记、归档 ZIP。风险台账覆盖缺件、逾期、工时比例、物料结存、费用资格及处理方式。政策资料支持国家、省、市条目、版本和来源。 | 归档中只包含实际登记的文书及证明。完整风险覆盖、长期保存、证据完整度和外部监管认定需逐项验收。 |
| 运行及安全 | 离线 Windows x64 包、自带运行环境、SQLite、本机私有文件目录、可重复启动。另附单位内网 HTTPS 入口，要求个人测试账号。 | 说明书正式环境使用 Python 3.11、MySQL、对象存储、异步服务、主备与负载均衡。本机包使用 Python 3.12 和 SQLite。正式云端、等保测评、加密存储、日志防篡改、异地备份、故障切换、峰值 SLA 及真实电子签章未验收。 |

## 验证记录

- 通过 HTTP 接口验证两个业务线的账号、权限、开户改密、立项到财务交接、退回重提、主管与经理回避、真实文件上传、DOCX、归档 ZIP、联签失效、结题勾稽及调整生效。
- 在独立测试库按 8 小时实到、6 小时研发、2 小时非研发录入工资及社保合计 800 元，核得项目 600 元、非研发 200 元。验证批量导入出现错误行时整批回滚，重复导入不产生重复费用。
- 使用模拟账例核对企业统一限额、委托境外限制、产品材料跨年以及资本化跨年和本年摊销。单次本机测试中，100 项目、10,000 条虚构凭证导入约 0.73 秒，计算约 0.44 秒，Excel 导出约 0.99 秒。正式并发和不同电脑的表现需另测。
- 用本机 Chrome 操作首次设置、登录、填项目、提交、换账号审核及历史稿，检查桌面和手机宽度。单位第二台实际电脑、单位内网域名与证书、签章供应商均未参与此轮测试。

正式开通前，按本文件逐项记录单位经办人、复核人、测试日期和差异。财务表单可对照国家税务总局 [A107012 表单与填写说明](https://12366.chinatax.gov.cn/bzds/037/037.html)。
