# 科研财税协同 MVP

这是一个政务网站原型，供承办、审核和督办人员体验科研财税协同办理。所有客户、项目和记录均为虚构资料。访客可在顶栏切换角色，进度保存在各自的浏览器。

## 体验流程

1. 进入工作台，打开示例订单的「费用归集」任务。
2. 切换为财务承办人，确认接件。查看科研线已确认的两个项目，编辑费用明细与材料索引。
3. 提交主管审核，再切换为复审经理。可以先退回一次，检查承办人重提后旧版本仍可查看。
4. 审核通过后切回派单经理，登记客户通过外部渠道确认的凭据，再归档并下载记录。
5. 同一订单可多次派发科研及财务任务。立项通过内部末级审核后，项目即对财务开放，客户签收仍在交付时登记。财务可按本期发生额提交底稿，无费用项目在汇总中列出。

## 十套政务界面

打开[政务界面展廊](https://ryan970910.github.io/xiongda-app-mvp/#designs)可任选两套方案并排试办。两侧分别从相同的示例数据开始，切换该侧方案可重新试办。进入完整版后，各方案共用本浏览器保存的办理进度。顶栏支持在当前业务页面切换方案。

| 界面 | 从首页可以做什么 |
| --- | --- |
| 综合办事大厅 | 输入客户、事项或订单号检索，按业务线缩小结果范围 |
| 一窗受理台 | 选择委托订单、受理事项，核对后派单 |
| 联合会审室 | 比较两版底稿，筛出变更，填写审核或退回意见 |
| 公文案卷馆 | 调阅材料目录、办理记录和版本，下载归档文件 |
| 督办日历 | 按月翻阅，选择某一天查看到期事项 |
| 资金核验台 | 从项目预算与底稿登记额查到费用类别、凭证及对应任务 |
| 双线协办室 | 并排查看科研与财务任务，按角色回复补件、确认关闭 |
| 事项导办册 | 按事项查阅准备材料、办理流程和交付成果，进入对应业务 |
| 运行指挥屏 | 从超期、三日内到期等统计切换到逐项督办清单 |
| 大字办事窗口 | 放大文字，按待办、审核或档案三个入口办理 |

综合办事大厅的建筑配图为虚构政务园区。分享某一方案时可直接复制其网址，例如[联合会审室](https://ryan970910.github.io/xiongda-app-mvp/?ui=review#dashboard)。

重大事项需要总监终审。财务发起的补件须由科研回复、财务关闭后才能提交审核。下载的 JSON 包含对应订单、项目、底稿各提交版本和处理记录。

## 本地运行

在仓库根目录启动静态 HTTP 服务，例如运行 `python -m http.server 8080`，再打开 `http://localhost:8080/`。网站无需构建依赖，可从 GitHub Pages 发布。

演示以角色切换模拟权限，用材料索引代替附件处理，用按项目明细代替正式税务报表。演示数据彼此独立，避免录入真实客户、凭证和确认信息。大模型接入留待后续。
